# کیان درّالتاج | KIAN GOLD

فروشگاه چندصفحه‌ای زیورآلات طلا با رابط فارسی/دری و راست‌چین، ساخته‌شده با HTML5، CSS3 و JavaScript ماژولار.

## اجرا
به دلیل استفاده از ES Modules و دریافت JSON، پروژه را با وب‌سرور محلی اجرا کنید:
```bash
python -m http.server 8000
```
سپس `http://localhost:8000` را باز کنید.

## امکانات فرانت‌اند
- ۱۶ صفحه فروشگاهی و ۵ صفحه پنل نمایشی
- فروشگاه، جستجو، فیلتر دسته/عیار/قیمت، مرتب‌سازی و نمایش بیشتر
- جزئیات محصول و محاسبه تفکیکی قیمت تخمینی
- سبد خرید و علاقه‌مندی‌ها با LocalStorage
- فرم‌های اعتبارسنجی‌شده، Checkout نمایشی و داشبورد نمونه
- قیمت طلای نمایشی، نمودار نمونه و هشدار عدم اتصال API
- دستیار نمایشی، منوی موبایل و طراحی واکنش‌گرا
- RTL فارسی، فونت Vazirmatn و پشتیبانی از prefers-reduced-motion

## محدودیت‌های نسخه نمایشی
قیمت طلا واقعی یا زنده نیست. درگاه پرداخت، ارسال ایمیل، احراز هویت، ذخیره سفارش و مدیریت محصولات روی سرور پیاده‌سازی نشده‌اند. پنل مدیریت امنیت ندارد و نباید در اینترنت به‌عنوان پنل واقعی استفاده شود. LocalStorage فقط برای آزمایش مرورگر است.

## ساختار
- صفحات HTML مستقل در ریشه و پوشه admin
- css: استایل پایه و صفحات
- js/components: اجزای مشترک
- js/services: محصولات، قیمت‌گذاری، سبد، علاقه‌مندی و دستیار
- data: داده نمونه JSON
- docs: برنامه مهاجرت و API
